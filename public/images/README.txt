Drop your photos here, named:
  img1.jpg
  img2.jpg
  img3.jpg
  img4.jpg
  img5.jpg
  img6.jpg

.jpg or .png both work. You don't need all 6 — any missing
ones are simply skipped and won't show a broken image.

After adding photos, rebuild with:
  npm install
  npm run build
then open dist/index.html.
